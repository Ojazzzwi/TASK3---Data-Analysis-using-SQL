# SQL for Data Analysis – Ecommerce Database

## Objective
The objective of this project is to use SQL to extract, manipulate, and analyze structured data from an Ecommerce database. The project demonstrates the use of various SQL operations for data analysis using MySQL.

## Tools Used
- MySQL
- MySQL Command Line Client

## Database
A sample Ecommerce database was created with the following tables:
- Customers
- Products
- Orders
- OrderDetails

The tables are connected using primary and foreign key relationships to simulate an online shopping system.

## SQL Concepts Covered
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions (SUM, AVG)
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- Views
- Indexes

## Queries Performed
1. Display all products priced above ₹5000.
2. Display products sorted by price in descending order.
3. Calculate the total quantity sold for each product.
4. Find the average product price.
5. Display customer names along with their order dates.
6. Find products priced above the average product price.
7. Calculate the total amount spent by each customer.

## Files Included
- `ecommerce_analysis.sql` – SQL script containing database creation, data insertion, and analysis queries.
- `README.md` – Project documentation.
- `Screenshots/` – Output screenshots of SQL queries.

## Learning Outcomes
- Created and managed relational database tables.
- Retrieved data using SQL queries.
- Performed data analysis using aggregate functions.
- Combined data from multiple tables using joins.
- Used subqueries for advanced filtering.
- Improved query performance using indexes.
- Created reusable views for simplified analysis.
